Demo and simulated datasets for Flood Forensics.

All files in this directory are **DEMO/SIMULATED** — not real government data.

| Directory | Contents |
|-----------|----------|
| `rainfall/` | Station rainfall time series |
| `flood_events/` | Flood incident records |
| `drains/` | Drainage network nodes |
| `maintenance/` | Maintenance work records |
| `water_levels/` | Water level sensor readings |
| `citizen_reports/` | Crowdsourced flood reports |
| `field_inspections/` | Before/after verification data |

Canonical demo event: **F2026-001** (seeded in Phase 2).
